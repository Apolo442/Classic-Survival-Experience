================================================================================
                    CLASSIC SURVIVAL EXPERIENCE - GUIA DOS VILLAGERS ESPECIAIS
================================================================================

COMO TRANSFORMAR UM VILLAGER EM ESPECIAL:
1. Tenha um Villager com a profissão desejada (Clérigo, Bibliotecário, etc.).
2. Renomeie uma Etiqueta (Name Tag) em uma Bigorna com um dos nomes aceitos.
3. Aplique a etiqueta no Villager.
4. O Villager se transformará instantaneamente em Especial:
   - Suas trocas serão personalizadas de acordo com o nível (Novice -> Master).
   - Ele sobe de nível normalmente ao realizar trocas.

--------------------------------------------------------------------------------
TAG UNIVERSAL (FUNCIONA PARA QUALQUER PROFISSÃO):
--------------------------------------------------------------------------------
Se você nomear a etiqueta como:
  * Especial
  * Special
O mod detecta automaticamente a profissão do Villager e o transforma no
Especial correspondente! (No caso de Fazendeiro, ativa o Fazendeiro 1).

COMANDOS ÚTEIS PARA TESTES / SPAWN DIRETO:
================================================================================
Você também pode invocar os villagers especiais diretamente usando:
  /function classic_survival:villager/summon/cleric
  /function classic_survival:villager/summon/librarian
  /function classic_survival:villager/summon/farmer_1
  /function classic_survival:villager/summon/farmer_2
  /function classic_survival:villager/summon/fisherman
  /function classic_survival:villager/summon/butcher
  /function classic_survival:villager/summon/leatherworker
  /function classic_survival:villager/summon/mason

Ou apontar a mira para qualquer villager existente e rodar:
  /function classic_survival:villager/convert_to_cleric
  /function classic_survival:villager/convert_to_fisherman
  (etc.)
